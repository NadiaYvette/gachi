# gachi-schema

Declarative Dhall configuration schemas and polytropos-dhall deserializers for `gachi`.

## Modules
- **`Gachi.Schema`**: Front door re-exporting project and Dhall schema definitions.
- **`Gachi.Schema.Project`**: Strongly-typed nominal records and open row representations for projects, packages, and remotes.
- **`Gachi.Schema.Dhall`**: Dhall schema definitions, encoders, decoders, and sample templates.
