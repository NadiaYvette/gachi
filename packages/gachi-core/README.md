# gachi-core

Foundational osteological memory representations and lock-free synchronization primitives for `gachi`.

## Modules
- **`Gachi.Core`**: High-level skeletal types, bone/joint identifiers, and chattering synchronization.
- **`Gachi.Osteology`**: Primitive unboxed memory layouts and contiguous array indexing.
